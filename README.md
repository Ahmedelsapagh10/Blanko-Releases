## 🎨 ما هو Blanko؟

**Blanko** سبورة رقمية مجانية بالكامل (Freeware) تتيح لك رسم أفكارك وتخطيط مشاريعك وتدوين ملاحظاتك بكل حرية وسلاسة.

- **🔒 بياناتك ملكك 100%**: التطبيق يعمل بالكامل على جهازك دون اتصال بالإنترنت، ولا يتطلب أي تسجيل دخول أو حسابات.
- **✨ مجاني تمامًا**: بدون اشتراكات، بدون إعلانات، وبدون أي مميزات مدفوعة خلف جدران حظر.
- **📁 مشاريع قابلة للنقل**: تصدير واستيراد بصيغة `.wboard` وتصدير بدقة فائقة حتى 4K PNG.
